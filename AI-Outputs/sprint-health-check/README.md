# Sprint Health Check — Outputs

Informes de salud del sprint generados por el agente [`sprint-health-check`](../../AI-Agents/sprint-health-check/).

## Contenido

| Archivo | Descripción | ¿Se commitea? |
|---------|-------------|---------------|
| `Sprint N - Health Check.md` | Informe final para el equipo | **Sí** |
| `raw.json` | Datos crudos de Jira | No (`.gitignore`) |
| `metrics.json` | Métricas calculadas | No (`.gitignore`) |

## Naming

```
Sprint 4 - Health Check.md
Sprint 5 - Health Check.md
```

Un archivo por ejecución del sprint activo al momento de correr el agente.
